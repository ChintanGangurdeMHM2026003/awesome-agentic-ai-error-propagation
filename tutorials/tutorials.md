# Tutorials and Learning Resources

## 1. Building Effective AI Agents

**Source:** Anthropic

**Purpose:** Provides practical guidance on designing effective AI agents, including common workflow and agentic architecture patterns.

**Relevance:** Helps understand the architecture and design principles behind multi-step autonomous agent systems.

**Link:** [Building Effective AI Agents](https://www.anthropic.com/engineering/building-effective-agents)

---

## 2. OpenAI Agents SDK Documentation

**Source:** OpenAI

**Purpose:** Provides documentation and tutorials for building agent applications using agents, tools, handoffs, guardrails, and other components.

**Relevance:** Helps understand how tool-using and multi-agent systems are structured and executed.

**Link:** [OpenAI Agents SDK Documentation](https://openai.github.io/openai-agents-python/)

---

## 3. Hugging Face Agents Course

**Source:** Hugging Face

**Purpose:** A structured course covering AI agent fundamentals, tools, reasoning, agent frameworks, practical implementations, and evaluation.

**Relevance:** Provides a comprehensive introduction to modern agent architectures and the Thought-Action-Observation cycle used in multi-step agents.

**Link:** [Hugging Face Agents Course](https://huggingface.co/learn/agents-course)

---

## 4. Microsoft AutoGen AgentChat Documentation

**Source:** Microsoft

**Purpose:** Provides tutorials and documentation for building agents, agent teams, tool-using workflows, and human-in-the-loop applications with AutoGen.

**Relevance:** Useful for understanding communication, coordination, delegation, and interaction between multiple agents.

**Link:** [Microsoft AutoGen Documentation](https://microsoft.github.io/autogen/stable/)

---

## 5. LangGraph Documentation

**Source:** LangChain

**Purpose:** Provides documentation for building long-running, stateful agent workflows with features such as persistence, durable execution, and human-in-the-loop control.

**Relevance:** Particularly useful for understanding state management, failure recovery, and execution across multiple agent steps.

**Link:** [LangGraph Documentation](https://docs.langchain.com/oss/python/langgraph/overview)

---

## 6. Demystifying Evals for AI Agents

**Source:** Anthropic

**Purpose:** Explains how to design evaluations for multi-turn AI agents, including tasks, trials, graders, transcripts, outcomes, and evaluation harnesses.

**Relevance:** Highly relevant to error propagation because it explains how mistakes can propagate and compound across multi-step agent execution and how evaluations can detect such failures.

**Link:** [Demystifying Evals for AI Agents](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents)
