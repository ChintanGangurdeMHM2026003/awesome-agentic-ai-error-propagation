### AgentBench

- **Paper:** *AgentBench: Evaluating LLMs as Agents*
- **Authors:** Xiao Liu et al.
- **Year:** 2024
- **Venue:** ICLR 2024
- **Link:** [Paper](https://proceedings.iclr.cc/paper_files/paper/2024/hash/e9df36b21ff4ee211a8b71ee8b7e9f57-Abstract-Conference.html)
- **Why it matters:** Evaluates LLM agents across eight interactive environments and highlights weaknesses in long-term reasoning and decision-making.

### WebShop

- **Paper:** *WebShop: Towards Scalable Real-World Web Interaction with Grounded Language Agents*
- **Authors:** Shunyu Yao et al.
- **Year:** 2022
- **Venue:** NeurIPS 2022
- **Link:** [Paper / DOI](https://doi.org/10.52202/068431-1508)
- **Why it matters:** Provides a multi-step web interaction environment where mistakes during navigation or tool use can affect subsequent actions.

### WebArena

- **Paper:** *WebArena: A Realistic Web Environment for Building Autonomous Agents*
- **Authors:** Shuyan Zhou et al.
- **Year:** 2024
- **Venue:** ICLR 2024
- **Link:** [Paper](https://openreview.net/forum?id=UNwWj5tGqK)
- **Why it matters:** Provides realistic long-horizon web tasks for evaluating autonomous agents and studying failures across sequences of dependent actions.

### ToolSandbox

- **Paper:** *ToolSandbox: A Stateful, Conversational, Interactive Evaluation Benchmark for LLM Tool Use Capabilities*
- **Authors:** Jiarui Lu et al.
- **Year:** 2025
- **Venue:** Findings of NAACL 2025
- **Link:** [Paper / DOI](https://doi.org/10.18653/v1/2025.findings-naacl.65)
- **Why it matters:** Evaluates stateful tool use and dependencies between tool calls, making it particularly useful for studying how errors propagate through agent workflows.

### GAIA

- **Paper:** *GAIA: A Benchmark for General AI Assistants*
- **Authors:** Grégoire Mialon et al.
- **Year:** 2023
- **Venue:** arXiv preprint
- **Link:** [Paper](https://arxiv.org/abs/2311.12983)
- **Why it matters:** Evaluates AI assistants on challenging real-world tasks involving reasoning, browsing, multimodal processing, and tool use.

### SWE-bench

- **Paper:** *SWE-bench: Can Language Models Resolve Real-world GitHub Issues?*
- **Authors:** Carlos E. Jimenez et al.
- **Year:** 2024
- **Venue:** ICLR 2024
- **Link:** [Paper](https://openreview.net/forum?id=VTF8yNQM66)
- **Why it matters:** Evaluates agents on real software-engineering tasks requiring multiple reasoning, coding, execution, and debugging steps.
